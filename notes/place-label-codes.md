# 居住地名の注記コードは縮尺帯ごとに分かれている

- 状態: 観測済み(2026-09-25)
- データ: [`data/observations/vector_tiles.csv`](../data/observations/vector_tiles.csv)
- 対象: 最適化ベクトルタイル `optimal_bvmap-v1.pmtiles`(Last-Modified: 2026-09-17)

## 観測したこと

`Anno` レイヤの vt_code のうち 13xx と 14xx を、ズームごとに数えた(北海道の6地点)。

| ズーム | 出た vt_code | 例 |
|---|---|---|
| z4–z7 | 1301, 1303 | 札幌 / 小樽・留萌・江別 |
| z8 | 1401, 1402 | 札幌 / 伊達・室蘭・登別 |
| z9–z10 | 1401, 1402, 1403 | 札幌 / 北広島・千歳 / 南幌・長沼・栗山 |
| z11–z14 | (13xx・14xx は出ない) | |

13xx と 14xx は同じズームに同時には出なかった。1302 はこの標本では一度も出ていない。

## スタイルでの扱い

一方の系列だけでフィルタすると、その系列の外の縮尺で地名が1件も出なくなる。
たとえば 14xx だけにすると、道全体が見える z6 前後で地図が無名になる。
スタイルでは両方の系列(1301–1303, 1401–1403)を指定している。

## 経緯

Orometry の開発中に、道全体の縮尺で地名が出ない不具合として見つかった(2026-08-18)。
このリポジトリでは、観測スクリプトで取り直して記録している。

## 標本の限界

6地点の真上のタイルしか見ていない。1403 が z8 に出ない、1302 が出ない、というのは
この標本での結果で、存在しないことの証明ではない。
