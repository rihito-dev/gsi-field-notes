# 居住地名の注記コードは縮尺帯ごとに分かれている

- 状態: 観測済み(2026-09-25)・仕様と照合済み(2026-09-26)
- データ: [`data/observations/vector_tiles.csv`](../data/observations/vector_tiles.csv)
- 対象: 最適化ベクトルタイル `optimal_bvmap-v1.pmtiles`(Last-Modified: 2026-09-17)

## 観測したこと

`Anno` レイヤの vt_code のうち 13xx と 14xx を、ズームごとに数えた(北海道の6地点)。

| ズーム | 出た vt_code | 例 |
|---|---|---|
| z4–z7 | 1301, 1303 | 札幌 / 小樽・留萌・江別 |
| z8 | 1401, 1402 | 札幌 / 伊達・室蘭・登別 |
| z9–z10 | 1401, 1402, 1403 | 札幌 / 北広島・千歳 / 南幌・長沼・栗山 |
| z11–z14 | (13xx・14xx は出ない) | |

13xx と 14xx は同じズームに同時には出なかった。1302 はこの標本では一度も出ていない。

## 仕様との照合

地理院の「注記分類コード一覧」([`spec-comparison.md`](spec-comparison.md))では、次のように定義されている。

| vt_code | 仕様の分類 | 仕様のズーム | 観測 |
|---|---|---|---|
| 1301 | 都市記号(人口100万人以上) | z4–z7 | z4–z7 |
| 1302 | 都市記号(人口50万〜100万人未満) | z4–z7 | 出なかった |
| 1303 | 都市記号(人口50万人未満) | z4–z7 | z4–z7 |
| 1401 | 都道府県所在地 | z8–z10 | z8–z10 |
| 1402 | 市役所・東京都の区役所(都道府県所在都市以外) | z8–z10 | z8–z10 |
| 1403 | 町・村役場・政令指定都市の区役所 | **z9–z10** | z9–z10 |

- 13xx は「都市記号」、14xx は「役所」の注記で、縮尺帯(z4–z7 と z8–z10)ごとに系列が分かれている。観測と一致した
- 1302 が出なかったのは、北海道に人口50万〜100万人の都市が無いためと考えられる(札幌は100万人以上、旭川は50万人未満)
- 1403 は仕様でも z9 からで、z8 には無い。Orometry の記録(2026-08-18)では 1403 を z8–z10 としていたが、仕様と今回の観測の方が正しい

## スタイルでの扱い

一方の系列だけでフィルタすると、その系列の外の縮尺で地名が1件も出なくなる。たとえば 14xx だけにすると、道全体が見える z6 前後で地図が無名になる。スタイルでは両方の系列(1301–1303, 1401–1403)を指定している。

## 経緯

Orometry の開発中に、道全体の縮尺で地名が出ない不具合として見つかった(2026-08-18)。このリポジトリでは、観測スクリプトで取り直して記録している。

## 標本の限界

6地点の真上のタイルしか見ていない。観測だけでは「出ない」ことは言えないが、1302 と 1403 のz8 については、上のとおり仕様の側で説明がつく。
